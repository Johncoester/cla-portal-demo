# MF-049 Conversation recipients

Source: Francis Santos, Nov 11 2026, "Missing Accounting Section and Conversation Recipient Issues" (Matt's ticket). Francis confirmed the list the same day.

## What the user should see

1. An HR-created Processor (designation Processor) has the same portal menu and the same file sections as a Processor who was not created in HR. Accounting is one of those sections when Admin > Modules has Accounting Live. An HR-only Employee login does not gain those sections.
2. Start conversation, opened from inside a file, offers only people on that file: parties, agents, the lender, the transaction coordinator, and CLA staff assigned to the file. A contact who is not on the file is not in the list.
3. A processor can type a first name, last name, and email. The email must look like an email. If that person is already on the file and has a portal login, they are included in the conversation. If they have no portal login, or they are not on the file yet, the portal adds them as a buyer, seller, buyer's agent, or listing agent (the person picks which), emails the usual portal invite, and holds the message until they sign in. That is the same path Share Files already uses. A bad email or a missing name stays on the form and says what to fix.
