# CRM Home My Tasks drops Related To

**Requested by:** Janine Santos, Nov 18 2026. Confirmed Nov 19 2026, 6:28 PM ET, with "Feedback 29 - Home tab tasks: Yes."

**Tracker:** CRM Feedback 29, Home tab tasks (follow-up to item 5).

**Status:** In progress. Not merged. Not Live. No database file.

## What the user sees

On CRM Home, the My Tasks list does not have a Related To column.

Contact Name is a link. It opens the record the task belongs to:

- A lead opens that lead.
- A client opens that client.
- A company opens that company.
- A deal opens that deal. The name shown is the property address.

Due Date, Subject, Status, Priority, and Edit stay as they are. The subject still opens the task.

A task whose record cannot be read still appears. Contact Name is blank, and it is not a link. A view with no tasks still says "No tasks in this view."

The task page still shows Related To. This change is only the list on Home.

## What is stored

Nothing new. The task already records which lead, client, company, or deal it belongs to. The list asks for those names once for each table the list uses. It does not ask again for each task.

## What this does not change

Who can open the CRM. Which tasks appear on Home. The task page. The file-page task list. Tasks under a pipeline opportunity, which has no page of its own, still leave Contact Name blank.
