# Coordinator on the agent's file (TC-3)

When a real estate agent is added to a file as the buyer's agent or the listing agent, each transaction coordinator linked to that agent is added on the same side.

## What the user sees

The coordinator shows on the file as Buyer's transaction coordinator or Listing transaction coordinator. Nobody picks the side. If that person is already on that side, they are not added again. If they assist both agents, they are on both sides.

Removing the agent leaves the coordinator on the file. A coordinator someone added by hand stays. A coordinator added from the link stays too. Staff remove a coordinator from Order Contacts when that person should leave.

## The coordinator's own login

On a file where their linked agent is the buyer's agent, the coordinator can do what that agent can do: see that side, finish the agent's tasks, schedule the settlement, and upload. On a file where the agent is the listing agent, they do what the listing agent can do. The same person can be the buyer side on one file and the listing side on another.

A task they finish says the coordinator completed it on behalf of the agent.

## What this does not change

The link itself (TC-2). The CLA Title staff role Transaction Coordinator. A contact type named Transaction coordinator (TC-4).

The one-pass document list still reads the coordinator's own row on the file. On the hosted portal, a coordinator sees a file they uploaded and a file marked for everyone. Seeing every buyer-side file the agent sees, through that one-pass read, is not in this change. The mock portal already treats them as the agent for documents.
