# Transaction coordinator on Add contact (TC-1)

A transaction coordinator is an outside assistant to one or more real estate agents. On a file, their side follows the agent they work for.

## What the user sees

On Order Contacts, Add contact, the role list does not include Transaction Coordinator. The coordinator choices are:

- Buyer's transaction coordinator: works for the buyer's agent
- Listing transaction coordinator: works for the listing agent

Choosing one of those shows that sentence, and says the person is an outside assistant. A portal login is not required. The name, email, and phone can be typed. A blank name with no company is refused, and what was typed stays.

Place Order and Parties use the same wording when a coordinator is added or changed.

A person already on the file as Transaction Coordinator still shows in the contacts list and on Parties, with that role name. They can still be edited or removed from the order. Nothing is deleted.

## What is saved

A new coordinator is saved as Buyer Agent TC or Listing Agent TC. The old role name is not written from Add contact.

## What this does not change

Edit order details still has the file-level Transaction Coordinator field. Agent profile linking, adding a coordinator automatically, a TC contact type, and what the coordinator can do on the file (TC-3) are other items. A refinance still has no coordinator.
