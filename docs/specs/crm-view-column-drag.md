## What the user sees

On New Custom View and Edit view, under Choose Columns, the selected columns are rows you drag.

Each row looks like a shown field in Manage columns on All Leads, All Clients, All Companies, or All Deals: a bordered row with a grab cursor. Drag a row onto another row and it takes that place in one move.

The focused row also moves one place with the up and down arrow keys. That is the same keyboard control as Manage columns.

Add still moves a field from Available into Selected. Remove still takes a field off Selected. The record name (Lead Name, Client Name, Company Name, or Deal Name) stays selected and has no remove button. It can sit in any place, including after another column.

Save stores that order. The list for the view shows the columns in that order. The name still opens the record.

A blank view name is refused. The column order you dragged stays on the form.

This is the same on Leads, Clients, Companies, and Deals.

## What this does not change

Which columns a new view starts with. Manage columns on the All list, except that it now shares this drag row. Who can open a record. Sharing, criteria, and sort. Reports. No new database file.
