# Reuse a contact by email (CONTACT-REUSE-1)

A person — a transaction coordinator, an agent, a buyer, a seller, or anyone else — can be on many files. When staff add someone to a file and type an email that is already on a contact, the portal uses that existing contact and adds them to the file. It does not create a second record, and it does not change the saved name, phone, or company.

## What the user sees

On Order Contacts → Add contact, and on File Overview when adding a buyer, seller, agent, lender, or transaction coordinator, staff can type a name, email, and phone, or pick someone already saved.

If the typed email already belongs to a contact, that person is added to the file. A short note says they were already a contact and a second record was not created. If that person is already on the file in the same role, the usual "already on this file" message still appears.

A blank email is unchanged: more than one contact may have no email.

Editing a contact and changing its email to one already used still fails, with the same plain message as before.

## What this does not change

Who can see a file. Portal logins and invites. Agent-to-TC links. The unique email rule on contacts (one contact per email). No database file.
