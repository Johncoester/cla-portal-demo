# ID images labeled with the person's name (MF-071)

Source: Matt Landsberg, Portal Feedback email Nov 25 2026, 2:47 PM ET (Gmail 1a214404e5bc56be). Confirmed 3:02/3:03 PM ET. Tracker row MF-071.

## What it does

When someone uploads the front or back of an ID, the stored document name is "{person's name} ID Front" or "{person's name} ID Back", plus the original file type (for example `.jpg`). The name comes from that task's person on the file, not a single buyer for the whole file. Sellers use the same pattern. Files already on TEST are not renamed.

## What stays the same

- The ID form fields themselves are unchanged (front and back, passport one image, from MF-070).
- Other document uploads keep the name the person chose.
