## What the user sees

On CRM Home, My Tasks (and every other choice in that same menu) fills Related To and Contact Name.

Both columns show the lead or client the task was created under. Intro Call shows Marcus Vance. Each name is a link. The link opens that lead's profile, or that client's profile.

A task that is not under a lead or a client leaves both columns blank. The rest of the list still shows.

## What is stored

Nothing new. The task already records which lead or client it belongs to. The list asks for those names once for the whole list. It does not ask again for each task.

## What this does not change

Who can open the CRM. Which tasks appear on Home. The file-page task list. Tasks created under a company or an opportunity.
