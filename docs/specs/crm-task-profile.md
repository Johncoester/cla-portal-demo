# CRM task profile link

**Requested by:** Janine, CRM Feedback 29 item 6. Confirmed Nov 16 2026.

**Tracker:** CRM Feedback 29 item 6.

**Status:** In progress. Pull request [339](https://github.com/Johncoester/cla-portal-demo/pull/339). Not merged. Not Live. No database file.

## What the user sees

On a CRM task, opened from Home or from Open Activities on a lead or client, the task shows that person's name. The name is a link to the lead or client profile. A second link says Back to that person.

A task on a company or an opportunity does not gain a made-up person link.

If the name cannot be read, the task still opens. It says to open Leads or Clients and find the person there.

## What is stored

Nothing new. The task already stores which record it belongs to. The name is read from that one lead or that one client. The Home task list does not do this read.

## What this does not change

The Home task columns. Who can open a task. The file-page task list. Notes, meetings, and calls.
