# Type parties onto a file (FF-049 / MF-046)

Staff can put a buyer, seller, buyer's agent, listing agent, or lender on a file by typing their details. They do not have to pick an existing contact, and the portal does not create a login or send an invite.

## What the user sees

On Place Order, each buyer and seller row has first name, last name, email, and phone, plus the entity fields that were already there. The search box stays, for choosing someone already saved. A typed name is enough. Email and phone are optional. A bad email or a partial phone is refused in plain words, and what was typed stays on the form.

Buyer's agent, listing agent, and lender each have a list of companies already saved and the agents or loan officers at those companies, plus boxes to type a person and a company who are not on the list.

On an open file, Parties has Add buyer, Add seller, Add buyer's agent, Add listing agent, and Add lender. Contacts → Add contact accepts the same typed details. Invite to portal is unchanged and is still a separate button.

## What is saved

A typed person is saved as a contact with no portal login, then linked to the file the same way a picked contact is. An existing contact that is picked is not rewritten. Nothing is invited. Who can see the file does not change, because a contact with no login cannot open it.

## What this does not change

Existing files, existing contacts, and the database rules for who can see a file. No new database file. Task Builder is not part of this.
