# Introduction Email To is a list of file parties (MF-066)

Source: Matt Landsberg, Portal Feedback email Nov 25 2026, 2:47 PM ET (Gmail 1a214404e5bc56be). Confirmed 3:02/3:03 PM ET. Tracker row MF-066.

## What it does

On the file Email tab, To is a list of people on the file. Each person is shown as "Name (Role) — email". You can check more than one person. Introduction Email still starts with the same default people (buyers, sellers, both agents, and a TC on the file who has an email). You can also type an address that is not on the file. New Email uses the same list, starting with no one checked.

## What stays the same

- Cc, Bcc, and the existing chips still work.
- Which roles are in the Introduction Email default set is unchanged.
- Welcome Opening and other templates are unchanged.
