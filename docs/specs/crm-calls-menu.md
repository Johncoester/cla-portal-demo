# CRM Calls menu link

**Requested by:** Janine, CRM Feedback 32 item 3. Confirmed Nov 18 2026.

**Status:** In progress. Not Live. No database file. See [ROADMAP.md](../../ROADMAP.md).

## What the user sees

In the CRM menu, Calls opens a list of calls that are already saved on a lead, client, or company. The subject opens that call. The list shows the call type, start time, status, and owner. If there are no calls, the page says "No calls yet."

A call that cannot be found says so and offers a way back to the list. A processor can see the list and cannot change it.

## What this does not change

This is not the Calls module. Scheduling, logging, and completing a call stay where they already are, on a lead, client, or company. Meetings and Tasks are not part of this change. Nothing is dialled, emailed, or texted. No database file.
