# Order Status milestones complete independently (MF-068)

Source: Matt Landsberg, Portal Feedback email Nov 25 2026, 2:47 PM ET (Gmail 1a214404e5bc56be). Confirmed 3:02/3:03 PM ET. Tracker row MF-068.

## What it does

Each Order Status milestone can be checked or unchecked on its own, in any order. Checking an earlier or later step does not automatically complete the others. The header shows how many of the 10 are complete. Checking Disbursed Funds still closes an open order. Unchecking it does not reopen the file; someone can change Order Status by hand if they need the file open again.

Existing files are backfilled: every step up to and including the file's previous stage is marked complete, so a file that was already advanced does not look empty.

## What stays the same

- The ten milestone names are unchanged (staff still see the slightly different labels for two of them).
- Agent and client "closing progress" still uses the highest completed step, so that scale does not change.
- A refinance uses the same bar.
