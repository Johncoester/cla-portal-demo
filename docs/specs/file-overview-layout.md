# File Overview layout (FF-105)

Source: Francis Santos, email "File Overview – UI Layout Rearrangement Only (No Data or Functionality Changes)", Nov 19 2026, 12:23 PM ET, with the image Order Parties Updated.png. She confirmed the corrections on Nov 19 2026, 2:35 PM ET (Gmail message 1a1f54e71ce7e8b6). Tracker row FF-105.

## What was asked

On the staff File Overview, rearrange the screen. Do not remove or change any existing field, saved value, or action.

1. Under the status tracker, four boxes: Transaction Type, Open Date, Close Date, Purchase Price. The values are already on the file.
2. A Closing Team row: Processor, CLA Transaction Coordinator, Licensed Settlement Agent, Sales Person. Show the assigned person. If nobody is assigned, the name is blank and the role title stays. Each salesperson gets a separate card. (FF-106b later relabels that CLA slot Preprocessor; see ff-106-closing-team-preprocessor.md.)
3. Parties stay. Processor, Title Company, and the sales rep are not removed. Selling Agent is the label for the buyer agent (the same role) and lines up with Listing Agent. Selling Agency and Listing Agency show the company already on that agent. Call, Email, copy, Source of business, All contacts, add-party buttons, Notes, Automation, and Preprocessor stay.
4. Licensed Settlement Agent is not the Closer. Closer stays.

## What it does

Staff see the tasks bar, then four boxes (the value large, the label under it), then Closing Team cards (a gray initials square, the name, then the role). Parties is one list in the picture's order. The buyer agent reads Selling Agent. The agent coordinators read Selling Agent TC and Listing Agent TC. Abstractor reads Title Abstractor. A Loan Officer row is shown only when that lender contact is already a loan officer. People the picture does not list stay under that list. Buyers, sellers, and agents keep the overview they already had. The staff tracker shows "Wire/Cash to Close Acknowledge" and "Funding Auth". The stored stage names are not changed.

## What is not in this change

No database file. There is no saved Licensed Settlement Agent on the file, so that card's name stays blank. The Closer field on Edit order details is unchanged. The status tracker words are unchanged. Not Live until someone checks it on TEST.
