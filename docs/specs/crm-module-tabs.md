# CRM module tabs

**Requested by:** Janine Santos, CRM Feedback 36, and the Feedback 28 shortcut-order follow-up. She confirmed the wording on Nov 20 2026, 12:40 PM ET ("yes, that's it"). Tracker row F36, row 416.

**Status:** In progress. Not Live. No database file. See [ROADMAP.md](../../ROADMAP.md).

## What the user sees

The CRM top tabs keep the order they already had, and add Tasks, Meetings, and Calls after Deals:

Home, Leads, Clients, Companies, Deals, Tasks, Meetings, Calls, Pipeline, Dashboards, Reports, Templates. An admin still sees Settings at the end.

Tasks opens CRM Home, where My Open Tasks is listed. That is the same place the old Task shortcut opened.

Calls opens the Calls list (`#/crm/calls`). Meetings has no list yet, so it is grey text, "Coming soon", and does not open a missing page. If Calls is switched off, that tab is hidden. If it is in testing, it keeps the beta badge.

The left menu is unchanged. CRM Home, Deals, Clients, Leads, Calls, and Email Templates stay where they are. Reports and Home still open.

## What this does not change

No new page is built for Meetings. The Calls list is the one already on main. It does not filter to one deal. No email is sent. No database file.
