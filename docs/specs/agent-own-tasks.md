# Agents see only their own tasks (FF-101a)

Real estate agents on a file — the buyer's agent, the listing agent, and a transaction coordinator acting for them — see only the tasks assigned to them. They do not see buyer, seller, or the other agent's tasks.

## What the user sees

On a file, the agent no longer has a general **Tasks** button or tab. They keep **My Tasks**, which lists only their own work. Opening the old Tasks address as an agent still shows My Tasks. Staff keep Tasks and My Tasks as they are today.

A coordinator linked to that agent (TC-3) still sees and can finish that agent's tasks, and the task says they did it on behalf of the agent. They do not see the client's tasks either.

## What this does not change

Staff views. Buyer and seller to-do lists. Completing a client task for them from the agent login is out of scope for this change: agents no longer see those client tasks.
