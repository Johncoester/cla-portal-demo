# File sidebar (FF-103)

Source: Francis Santos, Nov 18 2026, 6:19 PM ET, on "Re: [Written by AI] CLA portal updates – Nov 18". She confirmed the reading of her picture with "Yes" at 6:35 PM ET. Tracker item FF-103. Related to FF-061.

## What the user sees

Inside a file, the left sidebar runs top to bottom:

1. File Overview, Tasks, My Tasks, Inbox, Email, Documents.
2. ORDER, a label, not a link. Under it, General and Title fold open and closed.
3. CLOSING, a label. Under it, Charges folds.
4. Accounting, one item. Nothing is listed under it in the sidebar.
5. PREVIEW, a label, with Closing Disclosure and Settlement Statement.

General opens Basic Info, Contacts, Loan, Earnest & Commissions, Taxes & Prorations, Payoffs, and Other Contacts.

Title opens CPL, Policy Info & Rates, Commitment, and Final Policy.

Charges opens the charge sections that already exist: A Origination Charges, B Did Not Shop For, C Did Shop For, E Taxes & Fees, F Prepaids, G Escrow, H Other Charges, J Lender Credits, K/M Debits/Credits, and L/N Debits/Credits.

The second menu column that used to sit inside the file, next to this sidebar, is gone.

Accounting opens the ledger. On that page, Ledger, Receipts, Disbursements, Account Balances, and Balancing are tabs. Loan Funding is a tab there when the person could already open Funding, and it is also its own sidebar item so it does not require opening Accounting first. The balance summary stays on the ledger, in the content area, where it already was.

Scheduling Details, Agreements, Activity, Post-Closing, E-Recording, Wires, Prorations, CD details & escrow, Payment summary, and Edit history stay in the sidebar so those pages are still reachable.

## Who can see it

The rearranged menu is for someone who can already open Accounting. A buyer or seller keeps the shorter menu. A person who cannot open Accounting keeps the previous file menu.

Payoffs, Taxes & Prorations, and Other Contacts show only for someone who could already open them. Title pages show only when Title is on for that person. Final Policy, Wires, and Loan Funding show only for someone who could already open them.

## What it does not do

It does not add a Properties page. The address and parcel stay on File Overview. It does not change any form, calculation, or saved figure. It does not add a database change.

## Mobile (JC-MOBILE-1)

Source: John Coester, mobile video Nov 23 2026 3:34 PM ET, confirmed "yes" at 5:04 PM ET. Tracker item JC-MOBILE-1.

On a phone (860px and narrower), the This File file links start closed behind a This File button in the page flow, so the white menu does not cover the property address or order details. Tapping the button opens a drawer with a Close button and a dimmed backdrop. Tapping a file tab, Close, the backdrop, or Escape closes the drawer. On a computer the left sidebar is unchanged. A buyer or seller who already uses the light file shell (no sidebar) is unchanged. This does not change any page, calculation, or saved figure, and it does not add a database change.

The oversized sticky order header on a phone is a separate item (JC-MOBILE-2).

## Mobile order header (JC-MOBILE-2)

Source: John Coester, mobile video Nov 23 2026 3:34 PM ET, confirmed "yes" at 5:04 PM ET. Tracker item JC-MOBILE-2.

On a phone (860px and narrower), the order header at the top of File Overview (order number, stage, property address, price, parties, opened and county, settlement and disbursement dates) is not sticky. It scrolls away with the page so it does not stay pinned over half the screen. On a computer the header still stays pinned under the top bar. This does not change any page content, calculation, or saved figure, and it does not add a database change.
